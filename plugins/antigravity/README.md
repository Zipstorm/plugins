# SeekOut for Antigravity

Use your SeekOut account to find candidates, compare talent pools, plan a role, prepare for interviews, draft outreach, and manage your recruiting pipeline.

## Get connected

To install from GitHub, run `agy plugin install https://github.com/Zipstorm/plugins`. Once SeekOut is installed, open **Customizations → Installed → SeekOut → Accounts** in Antigravity and sign in with your SeekOut work account. Your organization needs MCP access and an eligible SeekOut license.

## Try it

Choose a starter on the plugin page or type it in a conversation.

- **Use SeekOut to find people for my open role and show me why they match.** Give a title like “CFO” when prompted. You can also add a location or a requirement. Candidate searches can use SeekOut credits.
- **Use SeekOut to compare the talent pool for my role in two locations.** For example, compare software engineers in Austin and Denver.
- **Use SeekOut to turn my job description into search criteria I can review.** Paste the description to get a draft of the requirements, preferences, and questions to take back to the hiring manager.
