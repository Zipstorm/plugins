# Use the right document and version

Choose [Google Drive](google-drive.md), [SharePoint](sharepoint.md) or [Notion](notion.md) for the selected source.

Start from the supplied or remembered file, folder/site and role. Resolve
ambiguous matches using title, owner, location and modified date. File IDs are
identity; titles are not unique. A tab or sheet link may select only part of a
file. Read relevant sections, not just search snippets, and label partial reads.

For tables, read actual headers and bounded row/column ranges. On a bad range,
reread metadata instead of guessing. Keep sheet, row coverage, filters and date
with counts. A synced index can lag or omit files; inaccessible is not absent.
For compensation, read the relevant approved band, not other employees' pay;
a team's band is internal evidence, not a market measurement.

Preserve JD structure and compare identified revisions for changes. Document
content proposes criteria under [shared criteria](../criteria.md); it does
not silently replace the role's accepted criteria. Read authorized candidate material
only for the intended person and audience; never retain candidate rows as memory.

For a requested deliverable, use the available create/update action and named
destination. Copy a template when asked rather than altering its original.
Preserve unrelated content in existing files. File creation and access sharing
are separate actions; check intended readers before adding a link elsewhere.
Read back when available. After an uncertain create, inspect the original result
or search the exact folder/title before creating another copy.

Without the required action, give the content or supported file with its remaining
manual step. Do not call it saved/uploaded. Standard SeekOut profile exports use
the export workflow. Follow [external actions](../external-actions.md).
