# Gmail

Use for role correspondence, prior candidate contact and requested mailbox drafts
or sends. Follow [mail work](mail.md); inspect the connected account and available
actions before a mailbox write.

Read a relevant thread through its latest reply. Keep message IDs separate from
thread IDs, and use a supported reply action to continue that conversation.
For scoped searches, use the action's supported sender/recipient, subject and
date filters; use Gmail query operators only when its schema accepts them.
Search count estimates are not exact totals. A mailbox URL does not switch the
connected account, and an attachment hit does not mean its contents were read.

Carry the mailbox identity, returned thread/draft/message ID and link into the
[workspace handoff](workspace-context.md). An email thread supplies context or
reply evidence; it does not update SeekOut outreach status by itself.
