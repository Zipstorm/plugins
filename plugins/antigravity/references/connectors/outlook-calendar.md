# Outlook Calendar

Use for intake meetings, candidate interviews and interviewer preparation.
Follow [calendar work](calendar.md). Select the requested mailbox/calendar;
reading a shared calendar does not establish permission to create on it.

Distinguish the organizer, attendees and any room/resource. Resolve the exact
recurring occurrence before an edit. Use the action's supported time-zone format
and inspect returned local times. Preserve meeting body and conferencing details
when adding preparation; do not replace them with a new brief. Use an attachment
or accessible document link only when the action supports it.

Carry calendar, event/occurrence identity and returned event link into the
[workspace handoff](workspace-context.md). Availability, an invitation and a
candidate's agreement to attend remain different facts.
