# Teams

Use for hiring-team discussions, meeting context and requested handoffs. Follow
[team chat](team-chat.md). Distinguish a team/channel conversation from a group
chat or meeting chat; the same display name is not a stable destination.

Read the relevant parent and replies within the requested scope. A meeting chat
is not the meeting transcript or an interview scorecard. A linked file may need
its own [SharePoint read](sharepoint.md); message access does not establish file
access. For a requested post, resolve the intended channel or chat before writing.

Carry tenant/account context where available, channel/chat/thread identity and
returned permalink into the [workspace handoff](workspace-context.md). Keep
private candidate assessment out of broadly visible team handoffs.
