# Deliverables

Make a file or save a report when requested; otherwise give the result in chat.
The producing skill owns analysis and figures; this reference owns packaging.

- Deliver the finished file using available client tools. If unavailable, say
  so and provide its content in chat.
- Inventory source searches, measurements and files and their scope/grain. Use only
  measured or supplied figures, preferably returned rates/shares. Rates from
  the recruiter's systems show numerator and denominator. Measure missing
  figures through their owning workflow or label them unknown.
- Reporting owns market and company measurements, push-back briefs and talent
  flows; use its workflow.
- Attach scope, filters, unit, grain and date to figures. Preserve SeekOut's
  warnings verbatim. End with a source ledger and returned links; for mail or
  calendar without links, name connector, search terms/folder and time window.
- Include only evidence-supported sections; name omissions once. Missing values
  within a supported section are “not measured,” never substitute metrics.
- Label files dated snapshots that do not refresh. Present observation,
  implication and recommendation; preserve the last complete version.
- Changes create a version/change list. Changed role, location, requirements,
  audience or goal require remeasurement; wording-only edits keep measurements.
- Follow [SeekOut brand](packs/seekout-brand.md). Customer colours/wordmark replace
  those only from a recruiter-supplied brand file, not web lookup.
- Hand off coverage, location and material limits briefly; keep the analysis in
  the file. Standard candidate profiles and ATS pushes use pipeline management's
  export to preserve fields/audit trail.
- Include personal contact details only if requested; never in wide circulation.
