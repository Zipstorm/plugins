# GitHub and open source

Search public profiles using the requested role and language/project terms.
Use clear alternatives for ambiguous technologies, such as Go/Golang. A named
GitHub organization supplies project context, not an employer or title. Search
the project's everyday name rather than its organization slug. Maintainer is
a contribution to verify, not a job title.
Do not invent public-search repository, star-count or maintainer filters.

A technology mention alone does not prove contribution. Read the linked work
when that evidence matters and the source is available. Distinguish author,
contributor, maintainer and current affiliation; “active in rust-lang” does not
mean “maintainer at rust-lang”. Missing evidence stays unknown.

Use stars, followers or repository counts only when requested, with their source
and date; they do not measure candidate fit. Confirm professional identity
before joining accounts. Keep the requested location, level and exclusions
while adding domain signals. For a direct GitHub search or combined slate, follow
sourcing's other-sources recipe and the tool's current syntax; SeekOut boolean
operators do not transfer there.
