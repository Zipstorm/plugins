# Industries

A kind of company the recruiter requires is carried, in order, by a company
power filter, the candidate's own industry category, a list of up to 200
employers you build and resolve to ids, or the sector's own words; sourcing's
query reference owns the choice. The hiring company's own sector, stage or size describes no
candidate.

## Industry categories

`industries` takes SeekOut's fixed categories (Financial Services,
Biotechnology, Healthcare and the rest), spelled exactly as a refusal lists
them. A category is the person's own profile
industry, never the employer's, so "people in financial services" is a
category while "engineers at fintech startups" is a list of employers.

## Vocabulary

| Term | Meaning/carrier | Exclusions or caveats |
| --- | --- | --- |
| Sector | Primary-business companies; matching company power filter or a built list; the person's industry category only when the ask is about the person | A diversified firm's product line is not membership |
| Competitors, investor portfolio, revenue band | A built list of the employers most likely to hold qualified people | No filter carries revenue or investors; say the list stands in for the class |
| Biotech | Biotech/pharma | Hospitals, universities, general healthcare |
| Cybersecurity | Security companies | General IT/big tech alone |
| Unicorn | Private valuation ≥$1B; a built list, checked on evidence | Public companies; no complete catalogue list |
| Funding stage | Latest private round; catalogue stage list when available | Public/past-stage firms; do not add unrequested size bands |
| Public company | Listed on an exchange, assessed from evidence | Size does not imply listing |
| Startup/venture-backed | Venture-funded private companies; startups catalogue | |
| Big tech/FAANG/YC/Fortune 500 | [Power filters](power-filters.md) when offered, otherwise a built list | No FAANG list |
| Nonprofit, hospital, government | The industry category when one matches, otherwise the sector's words as a required family, said to be a text match | Too broad for any list of companies |
| Stealth | No identifying employer set | Say it cannot be enforced that way |

## Company power filters

Browse the current pool/account catalogue; snapshots are not authority. Lists
may include all venture-funded startups, early stage (pre-seed/seed/A), mid
stage (B/C), late stage (D+), regional fintech, security or game companies.
Disclose a stage list wider than the requested round. Techstars unicorns cover
only Techstars-funded firms; Fortune 500 is revenue-ranked, not public-company status.

## Built lists

A built list is the companies that make up the class, as many as it needs up
to 200, the most relevant first, primary-business employers with every right
entity of each: the Fortune 500's companies by rank, the major private-equity
firms, an investor's known portfolio companies. Build it from what you know of
the class; company discovery returns employers within broad categories ranked
by headcount and does not resolve narrow sectors such as fintech or
cybersecurity. Resolve the names with name lookups in batches of 25, then
search once with every resolved id in one company filter at the recruiter's
tense. A name you added that does not resolve is dropped and counted; a name
the recruiter gave is never dropped. Unicorn and stage membership changes with
rounds and IPOs; date the list to what you know.

## Examples

For Series B, a returned mid-stage list also includes C: disclose that breadth
and assess the exact stage from evidence. For Snowflake's competitors, a built
list of data-warehouse and lakehouse companies, never all of Google, Amazon or
Microsoft. For UK healthtech, keep UK location, requested title/level and the
employer list separate.
