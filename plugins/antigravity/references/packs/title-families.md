# Title families

For `cur_title:` variants, sparse titles and evidence-based level checks.
Sourcing's query reference owns broadening; [worked searches](worked-searches.md)
shows complete clauses.

## Same-level variants

Apply the requested tier to every variant. Expanding PM, VP or CISO is a synonym,
not a level change.

| Role | Variants |
| --- | --- |
| Data Engineer | Data Platform Engineer, Data Infrastructure Engineer, Big Data Engineer |
| Machine Learning Engineer | ML Engineer, Deep Learning Engineer |
| Security Engineer | Application Security Engineer, AppSec Engineer, Information Security Engineer |
| Software Engineer | Software Developer |
| Sales Operations Manager | Sales Ops Manager, Revenue Operations Manager, RevOps Manager |
| Product Designer | None |
| CISO | Chief Information Security Officer |

## Levels

Keep the requested level/range. Adjacent tiers are not synonyms:

| Asked | Equivalent wording | Not equivalent |
| --- | --- | --- |
| Director | Director | Head, VP, Manager, Lead, Specialist |
| Head | Head of | Director, VP, Manager, Principal, Lead |
| Manager | Manager | Director, Lead, Specialist, Analyst, Coordinator, Associate |
| Lead | Lead, Team Lead, Team Leader | Manager, Director, Specialist |
| Senior | Senior, Sr | Staff, Principal, Lead, Junior, Associate |
| Staff | Staff | Senior Staff, Principal, Lead, Senior |
| Principal | Principal | Staff, Lead, Senior |
| Early career | Junior, Associate, Graduate, entry-level | Senior, Staff, Lead, Manager |
| CISO | CISO, Chief Information Security Officer | VP Information Security |

This applies to specialised roles too: Head of Product is not Group Product
Manager; Head of AI/ML is not AI/ML Manager; Policy Manager is not Analyst;
Implementation Consultant is not Manager/Specialist; Director of Implementation
is not Implementation Manager.

## Levels across companies

For evaluation, use documented scope, not assumed equivalence between employers'
titles or level ladders. Distinguish guided tasks, independent delivery, cross-team
technical leadership, organisational architecture and multi-organisation strategy.
Tech Lead/Architect/Fellow titles do not establish management responsibility.
A large title at a small company is a scope question for the screen, not dishonesty.

## Decomposition and standard titles

Separate base role from domain when profiles use generic titles:

| Request | Title terms | Free text |
| --- | --- | --- |
| ETL statisticians | Statistician, Biostatistician | ETL, data pipeline/warehouse, extract transform load |
| Consumer product managers | Product Manager | consumer, consumer products, B2C |
| MLOps engineers | MLOps Engineer, Machine Learning Engineer, ML Engineer | MLOps, ML operations, machine learning operations |
| AI/ML engineers | Machine Learning Engineer, ML Engineer, AI Engineer, AI/ML Engineer | None required; both functions were requested, never bare Engineer |
| Blockchain/smart contracts | Blockchain Developer/Engineer, Smart Contract Developer, Solidity Developer, Web3 Developer | solidity, ethereum, smart contract |

Blockchain/smart-contract requests do not broaden to Software/Backend Engineer.

## Non-US titles

Local equivalents must preserve level. Staff Software Engineer may appear as
Staff Engineer; Senior Staff, Principal and Lead are not automatic substitutes.
Check employer scope for Fellow/Principal Scientist/Chief Scientist and internal
IC-number mappings rather than translating them universally.
