# Status words

Use these for criterion-based screening, shortlists, applications, interview kits,
work samples and debriefs.

## Importance

`required` = must-have; `preferred` = nice-to-have; `excluded` = disqualifier the
person must be clear of.

## Status

Assign exactly one per criterion:

| Status | Evidence |
| --- | --- |
| `met` | Demonstrates the requirement |
| `partly met` | Demonstrates some, below the requested level; not an untested claim |
| `not met` | Positively establishes a shortfall; silence is insufficient |
| `unknown: not stated` | Record is silent |
| `unknown: not retrieved` | A fuller record would settle it but requires new spend |
| `unknown: conflicting` | Sources or interview judgments disagree |
| `unknown: needs a person` | Requires conversation/human judgment or was not covered |

Use the complete `unknown: <reason>` string with one listed reason. For `excluded`
criteria, `met` means clear of the disqualifier, `not met` means it applies;
uncertainty remains unknown, never clearance by absence.

Label candidate statements as claims. A skill listed without evidence in role
history/About is `unknown: needs a person`; ask where they used it. Current-work
criteria need current/recent evidence with dates. A statement admitting a
shortfall can establish `not met`; an asserted strength still needs evidence.
