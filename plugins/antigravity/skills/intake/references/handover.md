# Hand over a role

Start with what the next recruiter should do. Include the workspace, the role's
overview and its other saved records, newer proposals, decisions with rationale, live commitments and owners,
search scope, saved candidates, source dates and unresolved access gaps.
Read the linked work before describing it; unavailable records stay unavailable.

Keep completed work, partial results and next actions distinct. Do not copy
sensitive candidate or internal notes into a broader audience's handover.
A shared link grants no new access. Name the missing source and its owner when
known, and preserve evidence provenance so the next recruiter can resume
without repeating intake or mistaking old counts for current results.
