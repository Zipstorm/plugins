# Review the people already in front of you

Use the supplied resume/application, actual profile or authorized feedback for
the named role. Resolve consequential identity ambiguity using professional
anchors; a matching name alone is not enough. Do not search for a different
pool to answer an assessment request.

Read the current [criteria](../../../references/criteria.md), preserving
required, preferred and excluded conditions. Use explicit recruiter criteria
without asking again. Label inferred criteria as proposals; without a bar,
organize the evidence and ask only what changes the recommendation.

For each deciding criterion, give its [status](../../../references/status-words.md),
source/locator and a question that would settle the gap. Distinguish a
skills-list claim from demonstrated work. Missing or truncated material is
unknown, not failure; conflicting sources do not establish dishonesty. Read a
fuller SeekOut profile or other material only when it would change the
assessment.

Use these verdicts, without fit scores or probabilities:

- **Strong fit:** every requirement met and every exclusion confirmed clear.
- **Fit with gaps:** no demonstrated disqualifier; material evidence is missing
  or partly meets a requirement near the target.
- **Stretch:** no demonstrated disqualifier, but a requirement is partly met
  well below the target.
- **Not a fit:** evidence establishes a required shortfall or an exclusion.

Name the deciding evidence, confidence, uncertainty and next step. Rank only on the same
criteria version and comparable evidence; disclose unequal records and keep
ties. A short slate is valid. Keep reviewed, qualifying and pending counts
separate from the search's total or application count.

Never infer fit from protected traits, employer prestige, employment gaps,
voice or emotion. Interest, availability and logistics need the person's answer.
Preserve recruiter keep/pass decisions separately from criterion findings.
Accepted criteria changes require reassessing affected comparisons, not silently
changing the bar for one candidate. Follow shared [evidence rules](../../../references/evidence.md).
