# Start useful conversations

Deliver the requested draft, lookup, send, campaign action or reply. Copywriting
alone needs no setup read or contact lookup. Use known role
facts and candidate evidence, preserve the requested channel and mark gaps.

For addressed drafts or sending, reuse available addresses; look up missing
contacts only when needed, following the tool's credit/consent rules and
[contacts](references/contacts.md). Without an address, deliver the requested
draft and explain the sending blocker; offer another channel without switching.

Use the explicit target, otherwise this conversation's current work, then
consistent visible context. Ask only about remaining material ambiguity; keep
unrelated chats and roles separate. Follow-ups revise the current drafts or campaign.

## Follow the recruiter's outreach setting

Before preparing a candidate outreach run or sending, read SeekOut's outreach setup:

- **Destination.** *Connected email app* (default): write messages for the
  recruiter's own email plugin to send. *SeekOut workspace*: its sequences
  and campaigns send them.
- **Draft or send.** Chosen each time, never a setting. In SeekOut the
  recruiter picks *Preview drafts* (a few drafts, then send or refine) or
  *Send automatically* (to how many they chose), and each batch carries it as
  its behavior. Without a batch, deliver drafts and send only approved
  messages. An explicit draft or review request stays a draft.
- **Writing.** Follow the setup's saved style and end every email with its
  signature, else "Best," and the recruiter's full name. When they refine
  drafts, save what they asked for as their standing writing.

Use the saved destination unless the recruiter requests another, and save a
change only when they ask for it as a standing preference. Explain unavailable
destinations. Hiring-manager updates, reference requests and rejections use the
recruiter's own email regardless of this setting.

### Connected email app

For a requested candidate outreach run, SeekOut provides the next batch of up to 25 and
starts contact lookups; apply credit/consent rules before that step. Record each
person's outcome once the batch is done. Write messages in the conversation,
then send or save through the mail plugin as authorized. Without a connected
mail plugin, deliver the drafts. Use [direct messages](references/direct.md)
for sending and follow-ups.

### SeekOut workspace

Use [managed campaigns](references/campaigns.md) to draft sequences, add people,
or start, pause and review workspace campaigns. Sending needs a connected
SeekOut sending account; sequence drafting can proceed without it.

## Every message ends in the candidate's status

Outreach ends with each candidate's status in their workspace. SeekOut cannot
see the recruiter's email, so set it here:

- **Before writing,** read the workspace and skip people already contacted,
  not interested or opted out, unless a follow-up was asked for.
- **After drafts** not sent yet, ask once: send these, I sent them myself, or
  refine the drafts. A draft changes no status.
- **After a send** their email confirmed, or one the recruiter says they made,
  mark Contacted.
- **After a reply,** set the status [replies](references/replies.md) names.

Move a status forward only, unless the recruiter names one. A failed update
never stops outreach.

## Every path

If an action cannot run, finish the draft and name the remaining step.
Never silently switch sending methods or treat setup as permission to launch.

Personalize from actual work, preserve role facts and respect opt-outs.
Asked to see someone you are writing to, read their profile and show it in SeekOut.
A draft is not sent, an enrollment is not a launch, and an accepted send is
not delivery. Recommend the next step and why; continue only requested steps.
**Reporting** owns campaign analysis; **interviewing** owns booking meetings.
