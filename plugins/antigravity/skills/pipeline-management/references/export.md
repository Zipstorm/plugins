# Export the selected people

Use SeekOut to export to the requested file or ATS destination. If unclear, ask which: an ATS push
creates records in another system. Resolve the exact export-capable connection
and job; no job means prospects, not an application to an inferred role.

Take returned identities from the named search or workspace's saved people.
Keep the chosen set, source and destination stable across pages, retries and
other chats. Never manufacture keys or reconstruct an official profile export.
Export does not change stages, notes or dispositions.

An export may spend export credits: get the agreement SeekOut's export asks
for once (for a large batch, the recruiter's yes to how many people and the
most credits it can spend); never bypass it or ask for it again. Export and contact credits are
different; quote spend and balance only when returned.

Queued/accepted is pending, not filed or delivered. Follow the returned status
path. For uncertain SeekOut outcomes, recover with the identical request and
original key under [external actions](../../../references/external-actions.md),
never a fresh export. Report insufficient credits as the result states them,
not a smaller successful export unless confirmed.

Finish with actual completed count and download link or ATS/job destination.
Name pending, failed or omitted records separately. Do not claim a file download,
ATS application or delivery merely because the request was accepted.
