# Weekly update / digest

Compare current evidence with a verified, dated baseline at the same scope.
Without one, establish today's baseline without change claims. Separate new
events from outstanding work. Snapshot differences show net change, not who
moved or when, including in recommended actions.

Use markdown for meaningful changes, blockers and actions with owners and dates.
Read only relevant sources; identify skipped or failed ones. Preserve each
source's scope and successful-read timestamp for the next update; a failed
read must not advance it. Use [pipeline](pipeline-update.md) or [outreach](outreach-analytics.md)
counting rules only when including those sources. Scheduling requires an explicit request and
an available scheduler.
