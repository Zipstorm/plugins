# Funnel diagnosis

Use ATS stage history or supplied event exports; current snapshots cannot show
transitions or stage duration. Validate duplicates, stage order, withdrawals,
missing events and cohort maturity. Calculate from records with code, showing
numerator, denominator, unit and outcome window.

Explain bottlenecks, uncertainty and a bounded improvement experiment. For
source analysis, state attribution; compare mature progression and starts,
keeping unknown/multiple sources separate. Compare costs only where supplied
for equivalent periods; missing cost is not zero. Observed differences are
not causal. Suppress identifying groups and never stratify by protected
characteristics. Historical questions need evidence from then, not today's rerun.
