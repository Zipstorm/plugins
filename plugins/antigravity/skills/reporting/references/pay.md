# Pay research

Use supplied bands or dated public pages actually read, never profile counts,
search snippets or remembered rates. No credible source means no pay estimate.
Prefer employer-stated ranges; identify self-reported estimates and sample sizes.

Compare equivalent title, level, geography, currency, period and employment
basis. Separate base, bonus, equity and total compensation; do not overlay
incompatible distributions, invent percentiles or average conflicting sources.
Label an employer's own band as theirs. Individual offers belong to
**interviewing**. Never collect salary history.

## Pay bands in a report

When a report needs pay (a plan for a role, a market or a push-back brief), research
it before writing it: read the pages, using the web browsing the host offers.
Prefer, in order: the employer's own posted range (pay-transparency postings in
states that require them), then self-reported data with sample sizes, such as
levels.fyi for engineering levels, then other salary sites. Read each page; never
copy a figure from a search result's snippet.

Put the bands in the report as an `html` module titled "Pay bands": one row per
level, with columns for the level, the base range, and its source with the date
read. Add a total-compensation column only when a source gives total pay for the
same level. Close the table with one line saying the figures are external research,
not SeekOut data, and naming the sources. Size the module's `height` to its rows,
about 40 pixels a row plus 60. If no credible source was read for a level, leave
that level out rather than estimating it.

SeekOut does not measure demographic representation for these requests. Do not
infer it or use demographic filters, proxies or quotas. Offer job-related ways
to widen a pool while preserving its accepted anchors.
