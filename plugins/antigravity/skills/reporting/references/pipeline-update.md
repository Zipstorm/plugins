# Pipeline update

Explain pipeline state, risks and next actions across the requested roles.
Use the selected connection and read each requisition separately. Preserve
provider stage labels, coverage warnings and people/application units.

SeekOut snapshots sample people and summarize their applications, sometimes
across requisitions. Top lists are incomplete; never divide application counts
by sampled people or sum requisition samples into a portfolio total. Counts
are all-time except month-applied buckets. Snapshots establish current state,
not transitions, conversion or time in stage. A specific-stage ATS search can
provide a scoped people total. Markdown should support decisions, not repeat
stage counts.
