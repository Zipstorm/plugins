# Using SeekOut in Antigravity

Use the SeekOut MCP connection supplied by the installed plugin. For setup choices, use a question control when the host offers one, or ask in chat. The Find candidates starter asks its one role question in chat.
A chat preview shows up to three returned people in the chat reply with each name, current title, employer and returned link where available. Include the list even when an inline result view is available. Describe where results appeared only if the host confirms that placement.
Use other connections only when the necessary action is available in this conversation.

## Setup in Antigravity

Ask the source choice and the starter choice in separate turns. Wait for the recruiter
to choose. Use this client’s sign-in flow for the installed SeekOut connection. In Antigravity, open the plugin’s Accounts tab.
