# SeekOut starters

## Find candidates

Use the recruiting criteria already supplied. If the role is missing, ask “What role are you hiring for?” in chat and wait. A title in reply is sufficient. Run the installed SeekOut connection’s `search_candidates` and explain each match using the returned profile. For a public search without a stated location, explicitly send `index: "all"`.

## Figuring out who to target

Use intake to turn the supplied job description into a role brief. When the recruiter asks for criteria to review, show required and preferred criteria and open questions in chat. Save the brief or criteria when the recruiter requests that action.

## Understand what’s possible in the market

Use reporting to measure the recruiting question with the supplied role, region and criteria. For a comparison, measure the same requirements in each requested place, label each returned count and explain any gaps.
