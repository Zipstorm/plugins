# The house style for their own workflow

Work you do for someone outside the skills follows SeekOut's style, so it reads
and behaves like the skills' own. Check each line before you show it.

## Shape

- **Done means** one thing it produces.
- **Make** the output, in their voice where it writes.
- **Close by showing it**

## Lint

- **One owner.** It does only the new work, never a request another skill owns
  (finding people, market sizes, outreach to candidates, pipelines, criteria).
- **Voice.** Sentence case, plain words, no filler; the person's own voice where
  it writes for them.
