# Other sources and combined slates

Use the same role criteria across sources. Run searches only through available
capabilities; otherwise provide a paste-ready query or brief labelled untested.
A requested query draft can finish there. A request for candidates remains
unfulfilled until actual results exist.

Use each source's own syntax and supported fields, never SeekOut operators
such as `cur_title:` or `true:y`. For an unfamiliar search interface, read its
current documentation before composing a query. A natural-language brief
carries the role, level, required/preferred/excluded criteria, geography and
requested profile links. Name conditions that must be assessed after retrieval.

For GitHub or web research, search public professional evidence within the
request's scope. Repository languages, stars and followers are leads, not fit.
Read the work and confirm identity with professional anchors before attaching
it to a candidate. Search snippets alone do not establish a criterion.

Combine confirmed identities into one row while retaining every source link.
Distinguish retrieved, deduplicated and assessed people from total pool counts;
never sum overlapping pools. Keep uncertain matches separate. State which
sources ran and which are waiting on results.

Only SeekOut-returned people can be saved to its workspace. Match externally
found people first; unresolved matches retain their original source links.
Follow the relevant [connector note](../../../references/connectors/README.md).
