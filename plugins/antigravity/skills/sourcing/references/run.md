# Run and show a search

Use the role's workspace for a search that belongs to it. Reopen a saved search in SeekOut from its returned
reference; if results expired, rerun its saved criteria in SeekOut. Before
refining, read the search's current state in SeekOut and resend the whole query, filters and region with only the intended
change. Independent searches and what-ifs get separate searches. Follow shared
[recovery](../../../references/troubleshoot.md#recover-interrupted-work) when interrupted.

Inspect the returned query, resolved entities, applied filters and decision.
Dropped filters or a refused region mean the search did not run as requested,
not zero matches. Use complete returned retry filters for an unambiguous repair;
ask about materially ambiguous names. Do not substitute a parent company, drop
a named constraint or retry an uncertain paid operation automatically.

Check rows against required criteria and exclusions; use SeekOut to read fuller
profiles when previews cannot support a claim. Missing evidence remains unknown. Read more pages from
SeekOut only until the requested number is reached or results are exhausted. Preserve
partial results, returned profile/search identifiers and source links.

## Prior contact

For people being handed over, use available ATS/mail evidence to check prior
contact. Join by profile/email or corroborating professional anchors, not name
alone. Report outcome, date and source without private message text. Preserve
opt-outs; say when contact history could not be checked.

Present the search in SeekOut once, with scope, material limitations and any
refinement explained briefly in chat. Do not repeat the candidate list when
the pane already shows it. Follow shared [evidence](../../../references/evidence.md)
and the relevant [connector note](../../../references/connectors/README.md)
when reading another system.
