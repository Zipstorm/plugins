# Vendored Agent Plugins schemas

`1.0.0/plugin.schema.json` is the canonical schema published at <https://agent-plugins.org/schemas/1.0.0/plugin.schema.json>, vendored so validation remains offline and deterministic. Update it only together with the declared Agent Plugins specification version and a review of the normative specification.

The Agent Plugins project distributes this schema under the [Apache License 2.0](1.0.0/LICENSE-Apache-2.0.txt). The bundled file is an exact copy of the [upstream schema](https://github.com/agentplugins/agent-plugins-spec/blob/bccaba4ff6109ba67f753cb40dd69078239a3796/schemas/1.0.0/plugin.schema.json).

No MCP schema is vendored because this scaffold intentionally contains no MCP configuration.
